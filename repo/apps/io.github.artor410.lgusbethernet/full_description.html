Loads the r8152 kernel driver so Realtek RTL8152/RTL8153 USB Ethernet adapters work on LG webOS 6 TVs with the lm21u platform (e.g. OLED A1, 2021).

  • Requires root. Only loads on kernel 4.4.84 / platform lm21u and refuses on any other TV.
  • Load the driver on demand, or at every startup (with a boot-loop guard).
  • The TV configures the adapter's network by itself (DHCP, route, DNS).
  • Optional: make the adapter eth0, so webOS settings and streaming apps see the cable as connected (a light watcher keeps it after standby).
  • Optional Wi-Fi fallback: turns Wi-Fi on after 1 minute without cable link, and off again when the cable is back.
  • Built-in speed test.
  • Tested on OLED55A1PSA (webOS 6.5.3) with an RTL8153 adapter: 1 Gbit/s link.

Source: https://github.com/artor410/webOS6-usbrealtek-driver
